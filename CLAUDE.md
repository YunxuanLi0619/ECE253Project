## Agent skills

### Issue tracker

Issues are stored as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five labels (needs-triage / needs-info / ready-for-agent / ready-for-human / wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single context (root `CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
